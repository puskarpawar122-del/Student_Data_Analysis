# Student Data Analysis Project

A beginner Python project using Pandas, NumPy, and Matplotlib.

## Requirements
- Python 3
- pandas
- numpy
- matplotlib

## Install libraries
Open Command Prompt or the VS Code terminal in this folder and run:

```bash
pip install pandas numpy matplotlib
```

## Run the project

```bash
python main.py
```

## What the project does
1. Creates and explores a sample student dataset.
2. Finds missing values and fills them with column averages.
3. Removes duplicate rows and performs basic analysis.
4. Saves a cleaned dataset as `cleaned_students.csv`.
5. Creates bar, line, and pie charts as PNG files.

The CSV and chart files are generated when you run `main.py`.
